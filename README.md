# IntoTheBreachModManager
A mod manager for Into the Breach. Downloads and updates the modloader and Github-hosted mods based on a JSON file hosted in another repository.
Windows only.

# How to use

Download all files and run ITB Mod Manager.exe.
First, click "Choose game folder..." and navigate to your Into the Breach folder. If you can't find its location on your computer, use [Everything]([url](https://www.voidtools.com/)) to find it by searching Breach.exe. Its location determines where mods will be installed.
Click mods to see their descriptions. Double-click to subscribe or unsubscribe.
Then, click "Sync Subscriptions". It will automatically download the most recent version of the modloader and all subscribed mods.
Then, run Breach.exe. If you have any mods dependent on the memedit expansion, you will need to "calibrate" memedit. Just follow in-game instructions.

If you run into any bugs or issues, join the Discord by clicking the "Official Discord" button.
