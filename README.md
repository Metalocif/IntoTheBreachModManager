# Into the Breach Mod Manager
A mod manager for Into the Breach. Downloads and updates the modloader and Github-hosted mods based on a [catalogue](https://github.com/Metalocif/ItB-Workshop-Mod-List/blob/main/modlist.json) hosted in another repository, maintained by me.
Windows only.

# How to use

Download all files and run ITB Mod Manager.exe.\
It will download MinGit (used to download and update files) when you first run it if you don't have Git installed already.\
First, click "Choose game folder..." and navigate to your Into the Breach folder. If you can't find its location on your computer, use [Everything](https://www.voidtools.com/)) to find it by searching Breach.exe. Its location determines where mods will be installed.\
Click mods to see their descriptions. Double-click to subscribe or unsubscribe.\
Then, click "Sync Subscriptions". It will automatically download the most recent version of the modloader and all subscribed mods.\
Then, run Breach.exe. If you have any mods dependent on the memedit expansion, you will need to "calibrate" memedit. Just follow in-game instructions.\

If you run into any bugs or issues, join the Discord by clicking the "Official Discord" button. Tag @Metalocif to get in touch with me.
